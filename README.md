# 🗳️ Voting System

A simple **Voting System developed using Python**. This project demonstrates the basic concepts of Python programming by creating a system where registered voters can participate in an election and the results can be calculated and displayed.

## 📌 About the Project

The Voting System is a Python-based project designed to simulate a basic election process. It allows registered voters to cast their votes for available candidates and calculates the voting results.

This project was created as a learning project to practice Python programming concepts such as conditional statements, loops, functions, variables, and basic data handling.

## ✨ Features

* 🗳️ Allows registered voters to cast votes
* 👥 Supports multiple candidates
* 📊 Counts votes for each candidate
* 🏆 Determines the candidate with the highest number of votes
* ❌ Handles invalid voting choices
* 📋 Displays voting results
* 🐍 Developed entirely in Python

## 🛠️ Technologies Used

* **Python 3**
* Python built-in functions
* Basic Python data structures

## 🚀 How to Run

### 1. Install Python

Make sure **Python 3** is installed on your computer.

You can check your Python version using:

```bash
python --version
```

### 2. Clone the Repository

Clone this repository using:

```bash
git clone https://github.com/shahinam23/voting-system.git
```

Then move into the project directory:

```bash
cd voting-system
```

### 3. Run the Program

Run the Python file using:

```bash
python your_file_name.py
```

Replace `your_file_name.py` with the actual name of your Python file.
